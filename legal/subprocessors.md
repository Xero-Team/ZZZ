title: Subprocessor List
slug: subprocessors
---

**Last Updated**: September 1, 2026

ZZZ has no default subprocessors.

The editor does not create accounts, process payments, ingest telemetry,
host AI, or run collaboration through a ZZZ-operated service. There is
therefore no list of vendors that process customer personal data on
ZZZ's behalf by default.

If you configure a third-party provider, language server, MCP server,
Git host, or other integration, that destination is your vendor, not a
ZZZ subprocessor. See [Third-party terms](./third-party-terms.md) and
the [Privacy Policy](./privacy-policy.md).
