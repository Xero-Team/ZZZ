# Security Policy

ZZZ is a small, community-maintained, local-first editor. It accepts the
risks that come with that, and it does not run a private security process.
There is no security email address and no embargo window.

## Reporting a vulnerability

Report every vulnerability, including exploitable ones, publicly in this
repository's issue tracker:

<https://codeberg.org/ZZZEditor/ZZZ/issues/new>

Do not email maintainers. Public disclosure from the start is intentional:
it keeps the report, the reproduction steps, the discussion, and the
eventual fix in one place that anyone can read, now and later.

Please include:

- The affected version, tag, or commit.
- Steps to reproduce the issue.
- The potential impact you see.
- Anything else that would help someone fix it.

## What to expect

- Reports are triaged in public, like any other issue.
- Fixes are welcome as pull requests and follow the normal
  [contribution rules](./CONTRIBUTING.md).
- If a fix needs to land quickly, say so in the report and a maintainer
  will prioritise it.
