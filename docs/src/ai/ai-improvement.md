# AI Improvement and Data Collection

ZZZ does not collect training data.

Prompts, code context, ratings, and edit-prediction excerpts are not sent
to a ZZZ server. There is no opt-in program that shares conversations or
predictions for model training.

When you configure a remote language-model provider, that provider's
retention and training policy applies to the requests you send it. Review
those terms before sending data. Local providers such as Ollama and
llama.cpp stay on the machine you point at.

See [Privacy and Security](./privacy-and-security.md) and the
[privacy boundary](../development/privacy-boundary.md).
